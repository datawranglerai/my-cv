I built Talk Data to Me for the Google Gemma 3n Impact Challenge. It is a real-time commentary agent system that follows running agentic workflows and distils key decisions into commentary intended for public broadcast.

## Making a workflow legible

Multi-step agent systems can make consequential choices while their audience sees only an eventual output. This project explores a different presentation: commentary produced as the workflow runs, giving listeners a way to follow the decisions that shape its direction.

## The hackathon entry

I built the commentary agent system and developed its public-broadcast concept. The hackathon write-up describes how the entry turns decisions made during a workflow into commentary that an audience can follow.
